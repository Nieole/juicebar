# 运行时选择回写 config.toml，为此引入 toml_edit

托盘菜单允许切换 Primary Device，这个选择需要跨重启保留。备选方案是写进 `%APPDATA%` 下的状态
文件、完全不碰用户的配置；最终选择**回写 `config.toml`** 本身，理由是单一事实来源——用户打开
配置就能看到当前生效的选择，不必去猜某个隐藏状态文件里写了什么。

代价是 `toml`（serde 那套）序列化会洗掉注释，而这份配置的价值有一半在注释里（每一项都写了为什么
这么设计、哪些字段必须手填）。因此额外引入 **`toml_edit`** 做格式保留的原地编辑。

## Consequences

- 程序改用户手写文件，边界必须划死：**只补空缺和程序自己管的字段（`primary`、`config-refresh`
  填充的 Endpoint 块），绝不修改用户已经写过的值**。扫描结果与用户所写不一致时只在命令行提醒。
- 另有一个 `%APPDATA%` 状态文件仍然存在，但只放"上次已知读数"这类纯运行时缓存，不放用户可见的
  配置选择。
