# 队列约定

一趟实现队列（多张票、多棵 worktree 并行、逐张汇入）里那些不属于任何单张票的规矩。

## base 上的 gate 本来就是红的

**顺手修掉，让 gate 真的绿，并在报告里把这件事说清楚**——修的是哪几个文件、红的原因是什么
（工具链前进带来的新 lint？还是真写错了？）、改动是不是 gate 自己的工具吐出来的。

即使这让这张票动到了不属于它的文件，也照此办。

**为什么**：红着的 gate 是这趟队列的合约破了，它会被后面每一张票各撞一次、每个 agent 各排查
一次。而 gate 自己的工具（`cargo fmt`、`clippy --fix` 那类）吐出来的改动，在 N 棵 worktree 里
逐字相同，合并不会打架——这是"顺手修"在并行下仍然安全的全部依据。

**边界**：只修 gate 指出来的那几处，改动限于空白与等价改写。gate 红的原因若是**真的写错了**、
或者修它要动逻辑，那不是顺手修，那是上报。

（定于第 1 趟 `/settle`，出处是 parking lot Q5：票 01 在 `6d5eb1c` 上撞到两条 clippy 1.98 才有的
新 lint 和三个文件的格式，顺手修了，因此动到了 `src/bluetooth.rs` 与 `src/cli/caps.rs`。）
