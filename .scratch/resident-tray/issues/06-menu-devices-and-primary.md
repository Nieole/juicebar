# 06: 右键菜单：设备行，切换 Primary Device

**What to build:** 右键菜单第一次有了内容，照设计稿（`menu-as-designed` spec、ADR-0006；票面按那份
spec 改过）。

- 最顶上是此刻还挂着的告警，一条一行，点一下打开日志。
- 每台 Device 一行三段：名字；来源和多久前，这一次没拿到读数时换成短原因；右列写电量或图标状态的名字。
  该变灰的行变灰，Primary Device 前面打勾。
- 下面是"托盘上画哪一台 ›"：右列写用户的选择，里面是"自动（电量最低）"与每台 Device 的单选。点一下
  立刻生效，并写回配置，注释一句不丢。

`docs/gaps.md` 里"用户故事 17 是空的"从此有了按钮，"'自动（电量最低）'回写不了"也一并收掉。

**Blocked by:** 04；`menu-as-designed` 04（短原因）、05（告警挂着）、06（设计稿审完、菜单基准导出）

      右列、是否变灰、点了收到什么，并给票 07 的预览参数留好位置。Win32 外壳只把它画成普通原生菜单，

      与 `menu-as-designed` 07 都用它）
- [ ] "托盘上画哪一台"子菜单与设计稿导出的基准逐项比对，自动、钉死各一份

- [ ] 变灰：图标状态是 Stale、暂停、取数失败、Unknown、无已知值的那几行变灰；"读不到、上次已知值
