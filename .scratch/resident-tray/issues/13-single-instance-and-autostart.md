# 13: 单实例与开机自启

**What to build:** 能天天挂着用的最后两块。再启动一次时（会弹 UAC），新实例发现已有实例，就让老实例
弹一条"已经在托盘里了"，然后自己退出。菜单里的"开机自启"勾上即建一个计划任务（登录时触发、以最高
权限运行），取消即删——开机不弹 UAC。缺省不开。

这推翻了 `battery-readout` spec 里"注册表 Run 键"的计划：需要提权的程序，Windows 登录时不会从 Run
键启动它。

**Blocked by:** 06（菜单里的开关）

**Status:** ready-for-agent

- [ ] 单实例：具名互斥体；第二个实例通知老实例后退出。内核收到"有第二个实例来敲门"后弹通知，有用例
- [ ] 开机自启：勾上建计划任务，取消删掉；菜单的勾选状态以系统里那个任务存不存在为准，不另存一份
- [ ] **写一条 ADR**：程序清单要求提权 + 开机自启走计划任务，而不是 Run 键、也不是程序自己提权；
