# 07: 图标样式与菜单显示

**What to build:** ADR-0005 的八项设置真的能用了。`config.toml` 的 `[tray]` 表被读进来；右键菜单
多出"图标样式 ›"与"菜单显示 ›"两个子菜单，照设计稿（`menu-as-designed` 06 审过的那一版；票面按
`menu-as-designed` spec 改过）：

- 一级那一行右边不写字，第二层右边写当前值。
- 最里一层每个选项前面是一张预览，当前值那一项加粗（原型实机：圆点与预览不并排；用户 2026-09-15 定，
  parking lot Q280）。预览固定画 57，按托盘的真实尺寸、跟菜单实际的深浅画。
- "恢复默认"只恢复图标样式那六项。

改了立刻重画、写回配置。任务栏深浅色切换、显示缩放变化时，图标与预览都按新的调色与尺寸重画。

**Blocked by:** 06（子菜单挂在菜单上）；`menu-as-designed` 02（预览要的预乘字节）、03（菜单实际的深浅）
