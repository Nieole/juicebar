# 08: 低电通知

**What to build:** 电量跌破阈值时，不必盯着任务栏角落也会知道。**任何一台已登记的 Device**（不只是
Primary Device）的一次取数读到低于它自己阈值的电量、而此前没为它提醒过，就弹一条系统通知；之后读到
不低于阈值、或读到充电中，才重新武装。钉死了某一台当 Primary Device 时，另一台快没电也照样提醒。

**Blocked by:** 04

**Status:** resolved

- [x] 规则在内核里，用假时钟与罐装的一次取数结果驱动
- [x] 用例：跌破时提醒一次；持续低电不重复；读到充电中之后再跌破再提醒；回升到阈值以上后再跌破
      再提醒；拿上次已知值顶上的结果不触发；不是 Primary Device 的也提醒；单台阈值覆盖生效
- [x] "提醒过"只记在内存里：程序重启算新的开始，仍然低电就再提醒一次
- [x] 通知写明是哪台、电量多少，有用例断言确切字符串
- [ ] 手工验收：把阈值临时调高，看通知弹出一次、且只弹一次 → 收尾手工验收清单（编排者汇总交用户）
