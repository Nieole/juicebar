# 11: 格式保留回写与 primary 落盘

**What to build:** 程序改用户的配置文件时，不洗掉那些解释性注释（这份配置的价值有一半在注释里），
也绝不覆盖用户手改过的值——用户为绕开某个坑做的修改不该被默默改回去。同时，菜单里切换的
Primary Device 要落盘，重启后还在。

**Blocked by:** 09, 10

**Status:** ready-for-agent

- [ ] 引入格式保留的 TOML 编辑能力，并在依赖清单里写明收它的理由（照仓库惯例）
- [ ] 回写后配置里的注释完好无损
- [ ] 只补空缺和程序自己管的字段（`primary`、`config-refresh` 填充的 Endpoint 块）
- [ ] 用户手写过的值一律不修改；扫描结果与其不一致时只在命令行提醒
- [ ] Primary Device 的运行时选择回写 `config.toml`，重启后仍生效
- [ ] 测试：一份带注释、含用户手改值的配置，回写后注释与手改值都原样保留
