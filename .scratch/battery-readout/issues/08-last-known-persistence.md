# 08: 上次已知值持久化

**What to build:** 设备收进抽屉或关机后，用户仍能看到"上次是多少电"；重启 juicebar 不等于失忆。
但这个历史值必须会过期——它不能伪装成现状。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 每次成功的 Reading 写入 `%APPDATA%` 下的状态文件
- [ ] 重启后失联的 Device 仍显示上次已知值，并标注为陈旧
- [ ] 超过 `very_stale_after` 的持久化读数被丢弃
- [ ] 该状态文件只放运行时缓存，不放用户可见的配置选择
- [ ] 状态文件缺失或损坏时不影响启动，按"没有已知值"处理
