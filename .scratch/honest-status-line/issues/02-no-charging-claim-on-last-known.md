# 02: 退到上次已知值时不印充电态

**What to build:** 一只收进抽屉的设备，那一行不再断言它"充电中"。上次是多少电、多少电压
**照旧看得到**（那是那一刻的测量值，行尾"已陈旧，上次已知值"已经把它们限定完整了），
只有充电态那一格不印——它是一个**现在时的状态断言**，而状态在设备失联期间恰恰最可能变了
（收进抽屉、或者刚插上线）。

这不是加一条新机制，是把仓库**已有**的规矩用到它还没到的地方：说不上来的那一格整个不印
（键盘的充电态与键盘的电压本来就是这么处理的）。改完之后这条规矩在**所有**情形下一致。

**Blocked by:** None (can start immediately) —— 与票 01 碰的函数不相交，两张可并行。
