# 01: 失败那句话只说它答得出的话

**What to build:** 设备回了坏帧时，那一行不再说"都没读到"——我们**读到了**，只是读到的东西不
可信。今天那一行有**两个说同一句话的前缀**，而两句都是那个不准的说法；改完只剩一个标记，
并且它按失败的种类选：试过了都失败说「没有可信的读数」，一条都不在场 / 一条都没配照旧说
「读不到」。用户从此分得清"该去插线"和"该去关掉厂商上位机"——那是两件完全不同的事。

**Blocked by:** None (can start immediately) —— 与票 02 碰的函数不相交，两张可并行
（两张都会改到同一个测试文件，但落在不同区域）。

**Status:** ready-for-agent

- [ ] 失联那句话**整句只有一个出处**：失联原因那个函数拥有它的全部，**包括开头那个标记**；
      失败那个枚举的 `Display` 对失联那一支直接印它、不再自己加前缀。这不是新约定 ——
      那个 `Display` 的文档注释早就写着「两句话各自完整、**不共用前缀**」，今天那两个前缀
      本身才是违例
- [ ] **暂停那一支一个字都不改**（理由见 spec 的 Out of Scope：它今天不说假话）
- [ ] 标记按已有的三条分支选：**试过了都失败** → 「没有可信的读数」；**一条都不在场** /
      **一条都没配** → 「读不到」，措辞一个字不动（那句话被打磨过两轮）
- [ ] 那一行**不比今天更长**：一句标记换掉两个前缀
