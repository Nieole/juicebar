# 03: 重读读好了当场一轮

**What to build:** 手改配置文件存盘，图标与悬停提示约两秒内跟上，不再等某台 Device 的下一次取数——从文件改
`primary` 与从菜单里改一样快。（spec「一轮由配置开始」；parking lot Q252、Q292 ②。`CONTEXT.md`「一轮」已经
改成"它的输入变了就开始新的一轮"。）

- 重读读好了：换掉手上那一份、摘掉"配置读不了"、新登记的 Device 记成无已知值，然后**当场合成一轮**——走菜单换
  Primary Device 今天走的那条路，"当下"取手上最近的那一刻。
- 状态文件照菜单那一头的规矩：由配置开的那一轮没有新读到的东西要记，选出的 Primary Device 换了人才存、记
  `last_primary`；没换就一个字节不写。
- 程序自己写回（换 Primary、改 `[tray]`、登记）之后重读进来的那一轮，合成的结果与画着的一样，图标与悬停提示都不重发。
- 重读读不了不开一轮：手上的配置没换。
- 时钟走一格（Q164）、`[tray]` 换样式（Q300）、深浅与缩放换了（Q261）照旧只重画、不开一轮；`[tray]` 那条"当场重画"的用例里
  "不开新的一轮"那句注释改成"没有东西要存"的说法。
- 内核配置那一格与一轮那一格的模块文档随之改口（今天写着"换掉配置不重开一轮"那一段）。
