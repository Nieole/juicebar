# 06: 启动时配置读不了，托盘先空着起来

**What to build:** 开机时配置写坏了，托盘照样出现在通知区，右键菜单最顶上一行"读不了配置文件，托盘先空着起来"，
点它打开日志看完整的 TOML 错误；改好存盘，下一格读好、告警消失、每台各问一次——不必重启、不必再点 UAC。
（spec「启动时配置读不了」；parking lot Q251、grill 里的 Q5 与 Q9。`CONTEXT.md`「告警」已经改宽。）

- 文件在、却读不了（写坏、读不到）：外壳拿一份空配置起来，交回"启动时就读不了"那一个事件——与首次运行交回"草稿写好了"
  同一个口子；内核收到就挂告警。改好存盘走今天的重读那条路。
- 写不进草稿、读不到 `APPDATA` 仍然弹"juicebar 起不来"：那时连日志都写不了。
- 告警是**同一件事（配置文件）的两种说法**：运行中读不了仍是"读不了配置文件，沿用上一份读好的"；启动时读不了是"读不了
  配置文件，托盘先空着起来"。两种挂在同一格上（同一个 `Matter`），读好了都摘掉；完整原因照旧进日志；菜单基准里的告警
  占位仍是"配置文件读不了"那一种，基准文件不变。
- 悬停提示不动：空着起来那几分钟照旧说"一台 Device 都没有"那句，告警只住在菜单里。
- 取数失败类型上"启动时读不了没有上一份可沿用，托盘起不来"那句文档随之改口；外壳配置那一头"托盘就起不来"那段也改。
