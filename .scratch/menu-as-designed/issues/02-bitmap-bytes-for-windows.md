# 02: 位图交给 Windows 之前成为纯函数

**What to build:** 渲染器画对了，像素还可能在交给 Windows 的那一步被弄错：托盘图标要不预乘的 BGRA，
菜单里的预览位图要预乘过的 BGRA，行序也可能倒过来。哪一处弄反，托盘上的颜色或边缘就与设计稿不一样，
而渲染器的用例照样全绿。今天这一步写在外壳的 unsafe 块里，没有用例。

本票把"位图 → 交给 Windows 的字节"做成两个纯函数：托盘图标改走其中一个，另一个给菜单预览
（`resident-tray` 票 07）备好。托盘上看起来一点没变。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 纯函数一：位图 → 托盘图标用的字节（不预乘的 BGRA，自顶向下）。托盘图标改走它，外壳里只剩把
      字节交给 Windows 的那几行
- [x] 纯函数二：位图 → 菜单预览用的字节（预乘过的 BGRA，自顶向下）。宽度可以大于高度，给几张并排的
      预览用
- [x] 用例：不透明、半透明、全透明像素各一例，断言确切的字节；行序一例（第一行在最前）。两个函数都有
- [ ] 手工验收：托盘图标照旧，深浅两种任务栏下各看一眼，边缘没有黑边、也没有发白 → 收尾手工验收清单（编排者汇总交用户）
- [x] gate 三条全绿
