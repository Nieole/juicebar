# 03: 菜单深浅跟任务栏

**What to build:** 深色任务栏上右键，弹出来的菜单是深色的；浅色任务栏上是浅色的。菜单跟的是任务栏
（"Windows 模式"），不是"应用模式"，所以菜单、托盘图标，以及以后的预览小图，永远是同一套调色
（ADR-0006）。

Windows 没有让弹出菜单变深的公开接口，所以走 uxtheme 里未公开的那两个函数：把首选模式设成强制深色或
强制浅色，再刷新菜单主题。只在认得的 Windows 版本上启用；认不得就一个都不调，菜单是系统缺省的浅色。
今天的菜单只有"退出"一项，它也跟着变。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 每次弹出菜单之前，按任务栏此刻的深浅（外壳为托盘图标已经在读的那个值）强制深色或浅色，并刷新
      菜单主题；运行中切换任务栏的深浅，下一次弹出就跟上
- [x] 版本白名单是一个纯函数：Windows 10 1809 起与全部 Windows 11 认得，其余不认得（照 Notepad++ 的
      做法）。用例覆盖 1809 之前、1809、Windows 11
- [x] 认不得的版本上一个未公开函数都不调；认得、却取不到那两个函数时同样退回浅色，并记一条日志
- [x] 内核知道菜单此刻实际是深是浅：认得时就是任务栏的深浅，认不得时是浅色。`resident-tray` 票 07 的
      预览按它选调色
- [ ] 手工验收：深色任务栏、浅色任务栏各弹一次；"深色任务栏、浅色应用"弹一次，菜单是深的；运行中切
      一次深浅 → 收尾手工验收清单（编排者汇总交用户）
- [x] gate 三条全绿
