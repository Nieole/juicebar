# 07: 整张菜单与设计稿对上

**What to build:** 一级菜单是一张一张票长出来的：设备行与"托盘上画哪一台"在 `resident-tray` 票 06，
"图标样式"与"菜单显示"在 07，"打开配置文件"在 09，"登记设备"在 11、12，"开机自启"在 13。所以一级菜单
的整份基准，要等它们都落地才比得上。

本票收口：一级菜单与设计稿导出的基准逐项比对，再把整张菜单的截图对照走一遍。到这里，"菜单照设计稿"
才算做完。

**Blocked by:** `resident-tray` 06、07、09、12、13（11 经由 12）

**Status:** ready-for-agent

- [ ] 内核用例：一级菜单排成基准文本，与设计稿导出的三种情形（缺省、有告警、一台 Device 都没有）
      逐份比对；比对失败时打印两份文本的差异
- [ ] 逐一核对全部菜单基准都有用例在比：一级、托盘上画哪一台、图标样式与它的六个子菜单、菜单显示、
      登记设备。缺哪份补哪份
- [ ] 手工验收，截图与设计稿并排比：
      - 四档缩放（100% / 125% / 150% / 200%）× 深浅两种，每一档弹一级、托盘上画哪一台、图标样式的
        第二层、"灰状态"最里层
      - "深色任务栏、浅色应用"一次
      - 运行中切一次深浅
      - 托盘图标本身也在同几档里对一次
- [ ] 截图对不上的地方，先查是代码画错了还是设计稿该改（ADR-0005 的规矩），把结论写进本票
- [ ] gate 三条全绿
