# 03: 这一屏成为一个函数，`run` 退成一个壳

**What to build:** 「这一屏印成什么样」成为一个**测得到的函数**，`run` 退成一个只管构造与打印
的壳。买到的不是好看，是**一批今天谁也测不到的行为终于有了用例**——而每一条都是这个仓库明确
在意的那种：

- 进程枚举失败时**按"没在跑"走、只在 stderr 说一句**（fail open）。反过来会让一台 Win32 调用
  失败的机器永久显示"暂停中"、指名一个没在跑的进程——一句用户查不下去的假话（parking lot Q34
  就记着它测不到）
- 「配置 … 里一个 Device 都没有。」那一行，以及**它之后不提前 return** 这个决定——那正是最需要
  未登记 BLE 名单的时刻（MAC 就在那几行里等着抄）
- 未登记 BLE 那一段的标题、空行与缩进
- **「选出了 Primary 才记、选不出来什么都不动」**——"保持上次的选择"整条线挂在这一句上，而它
  断了不会红，只会悄悄永远选不出来

**Blocked by:** 01（呈现搬进自己的模块）—— 本票的落点在那个新模块里。这条边是有意的：本票要
往里加内容，那落在搬家之后，票 01 的 diff 才仍然是纯移动。

**Status:** ready-for-agent

- [ ] 新模块交出一个整屏函数：收**配置路径、配置、Endpoint 枚举、Clock、Processes、可变的上次
      已知值**，返回**两个输出流**的内容（要印到 stdout 的那几行 + 要印到 stderr 的告警）。
      **它自己不印**
- [ ] Clock **整个**进（每台设备各取一次"当下"，不能只收一个时刻）
- [ ] Processes **整个**进，**不是收探测结果**——那条 fail-open 规则因此一起进了可测范围。
      问不出来时那一趟不暂停，并交出一句告警
- [ ] 空配置那一行由它造（所以它要收配置路径），且**那之后不提前 return**：未登记名单照旧出现
- [ ] 状态文件的**两处写入都在里面**（记读数、记 Primary），`run` 只管两端的 load 与 save。
      同一份状态不分给两个人管
- [ ] `run` 退成壳：解析路径 → 不存在则走 bootstrap → load → 构造四样真东西 → 调它 →
      两个流分别打印 → save。**`run` 从此不自己造任何一行**
- [ ] 未登记 BLE 那一段那个函数**收私有**（它是这一屏的一段，不是一个概念），它那几条用例改从
      整屏驱动
- [ ] 公开面剩下的几样（整屏函数、一行的排版、那几行的合成、一行 Device 的成品）**文档说清各自
      是什么的接口**——一行的排版是「一行」的接口，那几行的合成是「哪一行挂 Primary 标注」的
      接口。**那句「`pub` 与 [`read`] 同理」在这一票里退掉**，它指向的对照早就不成立了
- [ ] 新模块的文档头补上「这道缝为什么在这儿」，以及**为什么它交出告警而不是自己印**
- [ ] 四条新用例，经整屏函数，每样至少一条：进程枚举失败按"没在跑"走并交出告警 / 空配置那一行
      且未登记名单照旧出现 / 未登记那一段的标题与缩进 / 选出了 Primary 才记、选不出来什么都不动
- [ ] prior art：假件全是现成的（公共那份里的假枚举、"当下"、缺省 general、几个设备构造器、
      扫到的 BLE、在跑的上位机）；排版那批用例今天本来就走真的取数那一步去拿一份读数，
      整屏那几条照这个路子写
- [ ] **用户可见的输出一个字不变**
- [ ] **不写 ADR**：这道缝的理由进模块文档头。`docs/adr/` 今天四条全是产品／协议决定，开一条
      结构类的会把那个目录的定义拓宽
