# 01: 呈现搬进自己的模块，公开面只换路径

**What to build:** 「这一屏印成什么样」从此是一个**有名字的模块**。一行的排版、那几行的合成、
未登记 BLE 那一段、以及一行 Device 的成品，全部搬进 `src/screen.rs`；`cli::status` 只剩 `run`，
与它的邻居（caps / config_refresh / probe / scan）同一个量级——**`src/cli/` 从此每个文件都只是
一条子命令的壳**。

对外这次搬家**不可见**：一个用户看得见的字符也不变，一条断言也不改。这是 `readout` 那次搬家的
第二步，同一条路。

**它是票 03 与票 04 的 prefactor**：把地方腾出来，后面两张才不必在一个刚移动过的位置上落笔。
本票整张的证据价值压在一句话上——**diff 是纯移动**，合并时靠它一眼就能核完。

**Blocked by:** None (can start immediately) —— 与票 02 一个文件都不相交，两张可并行。
