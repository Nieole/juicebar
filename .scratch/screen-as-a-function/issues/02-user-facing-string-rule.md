# 02: 用户可见的长句怎么写，成文

**What to build:** 下一个写用户可见字符串的人**不必再猜**，也不会第三次踩进同一个坑。

这个仓库用续行符折用户可见的长字符串已经栽过两次，两次都是续行符丢了、把源码里的缩进空格
印给了用户：一次已修（parking lot Q79），另一次**还在**——`probe` 那句"没有匹配的 collection"
里有 13 个字面空格，印在用户看得见的那句话中间。

本票立一条规矩把这一类关掉，并收掉那个活口。**那个活口不算路过**：票面点名要立这条规矩，
而它是这条规矩今天唯一的反例（`docs/agents/queue-conventions.md` 第 2 条）。

顺带补上一个一直空着的位置：`/code-review` 的 Standards 轴找的是仓库里记载"代码该怎么写"的
文件，而本仓库**一条成文标准都没有**，那条轴至今只跑在通用的气味基线上——那份技能明写着
"仓库的成文标准永远压过基线"。这将是第一条。

**Blocked by:** None (can start immediately) —— 与其余四张票**一个文件都不相交**，全程可并行。
